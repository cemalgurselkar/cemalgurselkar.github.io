# Introduction

![Cemal Gürsel Developing](/images/profile.jpg)

Computer Vision (CV) is one of the most exciting fields in Artificial Intelligence. It enables computers to "see" and interpret the visual world.

## The Evolution of Architecture

In the early days, we relied on hand-crafted features like SIFT and HOG. Today, **Convolutional Neural Networks (CNNs)** and **Vision Transformers (ViTs)** dominate the landscape.

```python
import torch
import torch.nn as nn

class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 16, kernel_size=3, padding=1)
        self.relu = nn.ReLU()
        
    def forward(self, x):
        return self.relu(self.conv1(x))
```

## Mathematical Foundation

The core operation of a CNN is the **convolution**. For an input image $I$ and kernel $K$:

$$
(I * K)(i, j) = \sum_m \sum_n I(m, n) K(i-m, j-n)
$$

This operation allows the network to learn spatial hierarchies of features.
